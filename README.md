# Ray Engineering Skill

Payload lives in `ray-engineering-skill/`. The repository root is packaging and review space; copy or install the `ray-engineering-skill/` directory as the skill.

Current version: see `VERSION`.

## Use

1. Read `ray-engineering-skill/SKILL.md` first.
2. Follow its phase routes to `workflows/`, `checklists/`, and `templates/`.
3. For an ongoing repository, start with `ray-engineering-skill/workflows/joining.md`.

## Layout

- `ray-engineering-skill/SKILL.md` — principles, gates, routing, autonomy boundary, completion contract.
- `ray-engineering-skill/MANIFEST.md` — file map and internal precedence.
- `ray-engineering-skill/workflows/` — executable procedures.
- `ray-engineering-skill/checklists/` — pass/fail gate criteria.
- `ray-engineering-skill/templates/` — reusable project artifacts.
- `REVIEW.md` — internal review notes; not part of the skill payload.
