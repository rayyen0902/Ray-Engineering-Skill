# Architecture Workflow

## Objective

Produce enough architecture to implement safely without speculative over-design.

## Process

1. Read approved requirements.
2. Identify system boundaries.
3. Identify major components.
4. Define data ownership.
5. Define interfaces.
6. Trace primary data flows.
7. Identify security boundaries.
8. Identify operational requirements.
9. Consider failure modes.
10. Identify irreversible or high-impact decisions.
11. Create ADRs where appropriate.
12. Obtain architecture approval.

## Rule

Architecture should be proportional to project complexity.
