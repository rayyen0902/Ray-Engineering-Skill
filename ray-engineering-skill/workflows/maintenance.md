# Maintenance Workflow

After meaningful changes:

1. Update project state.
2. Update affected requirements or architecture documents.
3. Record material decisions as ADRs.
4. Update tests.
5. Update changelog for user-visible changes.
6. Remove obsolete documentation.
7. Promote measured environment facts and pitfalls to `AGENTS.md` verified facts when they affect future agents.
8. Identify the next priority.
9. File the completion report for meaningful work using `templates/COMPLETION_REPORT.md`.

Documentation must describe the current system, not an idealized historical version.
