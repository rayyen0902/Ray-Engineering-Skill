# Project Initialization Workflow

## Goal

Create the minimum viable project-management system before substantial coding.

## Steps

1. Inspect repository.
2. Identify existing documentation and code.
3. Determine whether the project is new, inherited, or partially implemented.
4. Ask only critical questions.
5. Establish problem, users, goals, constraints, and non-goals.
6. Create/update README.
7. Create/update SPEC.
8. Create/update PROJECT_STATE.
9. Establish AGENTS rules.
10. Determine whether architecture design is required.
11. Do not begin substantial implementation until the appropriate approval gate is passed.

## Exit condition

The project has an explicit problem, scope, initial requirements, current state, and next action.
