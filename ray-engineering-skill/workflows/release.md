# Release Workflow

## Preconditions

- Requirements satisfied.
- Relevant tests pass.
- No unresolved critical issues.
- Configuration and migrations reviewed.
- Release notes/changelog updated.

## Process

1. Run release checks.
2. Review version and dependencies.
3. Verify deployment configuration.
4. Verify migration/rollback strategy where applicable.
5. Create release.
6. Update PROJECT_STATE.
7. Record known limitations and next priority.
